# Casino Cartes Duel

Jeu de cartes stratégique en trois manches contre un Croupier IA. L’application
est conçue pour ordinateur, tablette et smartphone, sans mise ni argent réel.

## Stack

- Next.js App Router
- React et TypeScript
- Tailwind CSS via PostCSS
- Déploiement Vercel

## Développement

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run typecheck
npm run lint
npm test
```

`npm test` compile l’application en production, démarre le serveur Next.js et
vérifie la page d’accueil ainsi que l’image de prévisualisation sociale.
